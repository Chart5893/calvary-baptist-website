# Calvary Baptist Church — Website Concept

A responsive static website for Calvary Baptist Church in Trenton, Georgia. **Development concept only; not an official church website.** Church leadership should approve all content before launch.

## Pages
Home, About Us, Worship, I'm New, Give, Connect.

## Preview locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Weekly message
Edit `content.js` to update the message title, date, scripture, summary, and YouTube URL. This is a temporary low-tech publishing approach; a pastor-friendly admin interface is planned.

## Before launch
Confirm church address, phone, service times, pastor, statement of faith, ministry activities, and church-approved photos. Choose a secure donation provider and a privacy-conscious contact workflow. Establish church ownership of its domain and hosting.

## Deployment
**Do not enable GitHub Pages yet.** No deployment workflow is included. The site will eventually be hosted on a church-owned domain.

No payment processing or contact-form submission is enabled.
